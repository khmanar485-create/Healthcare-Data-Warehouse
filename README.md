# 🏥 Healthcare Data Warehouse

## Description
Projet académique de développement d'un entrepôt de données pour l'analyse des admissions hospitalières.

## Contenu
- `hospital_dwh_project.ipynb` : Code ETL complet (pygramETL + visualisations)
- `healthcare_dwh_export.csv` : Export pour Power BI
- 8 KPIs Matplotlib (graphiques)
- Dashboards Power BI (captures)

## Technologies
PostgreSQL | Python | pygramETL | Pandas | Matplotlib | Power BI
